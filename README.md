# Enpm 690 Final Project 

This repository contains the code for implementation of the FINAL_PROJECT

### Prerequisites

1. Python 3.10 in conda environment

### Installation

Follow these steps to get up and running:

1. **Clone the repository:**
    ```bash
    git clone <https://github.com/SYED-ABRARUDDIN/ENPM690_FINAL_PROJECT.git>
    cd <ENPM690_FINAL_PROJECT>
    ```

2. **Install the required packages:**
    ```bash
    pip install -r requirements.txt
    ```

## Usage

After you've installed the prerequisites and have you directory set up correctly, you can run the agent:

```bash
python main.py
```
